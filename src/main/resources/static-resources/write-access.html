Write access

Choose which systems may run write tools through the gateway.

A user can write on a system only if it is enabled here and they are in the writer group. Every other system is read-only for everyone.

Every system asks each user for the same permissions whatever their role, so enabling one needs no reconnect. Turning writes off does not revoke tokens people already hold, it only stops the gateway from using them.

Every change is recorded in the Interactions log.

No writer group is configured, so nobody can write regardless of this selection.
