How to use with Claude

Add this gateway to your Claude client to start using your connected tools.

Before you start: Make sure you've connected the services you want on the Connections page. Only connected services will be available to Claude.
Easiest

Claude — connect via the Connectors list

The gateway is already listed in Claude's built-in connector directory — no URL needed.

  1. Open Claude and go to Settings → Connectors
  2. Find Akka MCP Gateway and click Connect
  3. Follow the sign-in prompt to authenticate with your Okta account
First time only: A browser window will open for Okta SSO sign-in. After that, it reconnects automatically.

Verify it's working

Once added, ask Claude: "What tools do you have available?" — you should see tools from your connected services. You can also ask Claude to call howto_get_started for a built-in summary of everything available.

FAQ

How do I remove the gateway from Claude Code?

Run claude mcp remove akka-mcp-gateway in your terminal.

See the MCP Tools page for a full list of tools from all connected services.
