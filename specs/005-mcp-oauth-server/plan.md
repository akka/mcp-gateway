# Implementation Plan: MCP OAuth 2.1 Authorization Server

**Branch**: `005-mcp-oauth-server` | **Date**: 2026-04-28 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/005-mcp-oauth-server/spec.md`

## Summary

Add an OAuth 2.1 Authorization Server to this Akka service so MCP clients can connect using only the server URL. The service handles Dynamic Client Registration, a consent screen backed by Okta authentication, and issues bearer tokens that are reused session UUIDs — enabling both cookie and bearer token access to all protected endpoints. Three new Key Value Entities are introduced; the existing `UserSessionEntity`, `OidcPendingLoginEntity`, and `AbstractProtectedEndpoint` are minimally modified.

## Technical Context

**Language/Version**: Java 21 (existing project)
**Primary Dependencies**: Akka SDK 3.4+, Akka HTTP (embedded), Jackson (existing)
**Storage**: Akka Key Value Entities (3 new: OAuthClientEntity, OAuthAuthorizationCodeEntity, OAuthPendingAuthorizationEntity)
**Testing**: JUnit 5, Akka TestKit, EventSourcedTestKit / KeyValueEntityTestKit
**Target Platform**: Akka service (local dev + Akka platform)
**Project Type**: Web service
**Performance Goals**: Metadata endpoints <200ms (static JSON); token endpoint <500ms
**Constraints**: PKCE S256 mandatory; single-use codes; 10-minute code TTL; 8-hour access token TTL
**New Env Var**: `MCP_BASE_URL` (default `http://localhost:9000`) — the public base URL of this service

## Implementation Details

### Phase 1 — Domain Layer

#### `OAuthClient` (domain record)
```java
package com.example.domain;

import java.time.Instant;

public record OAuthClient(String clientId, String clientName, String redirectUri, Instant registeredAt) {
    public static OAuthClient empty() { return new OAuthClient(null, null, null, null); }
    public boolean isEmpty() { return clientId == null; }
}
```

#### `OAuthAuthorizationCode` (domain record)
```java
package com.example.domain;

import java.time.Instant;

public record OAuthAuthorizationCode(
    String code, String clientId, String sessionToken,
    String redirectUri, String codeChallenge, String codeChallengeMethod,
    String scope, Instant expiresAt, boolean used
) {
    public static OAuthAuthorizationCode empty() { return new OAuthAuthorizationCode(null,null,null,null,null,null,null,null,false); }
    public boolean isEmpty() { return code == null; }
    public boolean isExpired() { return expiresAt == null || Instant.now().isAfter(expiresAt); }
    public OAuthAuthorizationCode markUsed() { return new OAuthAuthorizationCode(code,clientId,sessionToken,redirectUri,codeChallenge,codeChallengeMethod,scope,expiresAt,true); }
}
```

#### `OAuthPendingAuthorization` (domain record)
```java
package com.example.domain;

import java.time.Instant;

public record OAuthPendingAuthorization(
    String clientId, String redirectUri, String codeChallenge,
    String codeChallengeMethod, String scope, String clientState, Instant expiresAt
) {
    public static OAuthPendingAuthorization empty() { return new OAuthPendingAuthorization(null,null,null,null,null,null,null); }
    public boolean isEmpty() { return clientId == null; }
    public boolean isExpired() { return expiresAt == null || Instant.now().isAfter(expiresAt); }
}
```

### Phase 3 — API Layer

#### `McpOAuthMetadataEndpoint`
- `@HttpEndpoint("/.well-known")`, `@Acl(allow = @Acl.Matcher(principal = Acl.Principal.INTERNET))`
- Reads `MCP_BASE_URL` env var (default `http://localhost:9000`) in constructor
- `@Get("/oauth-protected-resource")` → returns `ProtectedResourceMetadata` record as JSON
- `@Get("/oauth-authorization-server")` → returns `AuthorizationServerMetadata` record as JSON
- No entity lookups; pure configuration-driven responses

**Response records** (defined as inner records):
```java
record ProtectedResourceMetadata(String resource, List<String> authorization_servers, List<String> scopes_supported, List<String> bearer_methods_supported) {}
record AuthorizationServerMetadata(String issuer, String authorization_endpoint, String token_endpoint, String registration_endpoint, List<String> response_types_supported, List<String> grant_types_supported, List<String> code_challenge_methods_supported) {}
```

#### `McpOAuthEndpoint`
- `@HttpEndpoint("/oauth2")`, `@Acl(allow = @Acl.Matcher(principal = Acl.Principal.INTERNET))`
- Extends `AbstractProtectedEndpoint` to access `requireSession()` and `getSessionToken()`
- Reads `MCP_BASE_URL` env var + reuses Okta env vars from `AuthEndpoint`
- Contains static `pkceChallenge(verifier)` method (SHA-256 + Base64URL, no padding) — can be package-private static or extracted

**Routes**:
| Method | Path | Handler |
|--------|------|---------|
| `@Post("/register")` | Body: `RegisterRequest(List<String> redirect_uris, String client_name)` | `register(RegisterRequest)` |
| `@Get("/authorize")` | Query params via `requestContext()` | `authorize()` |
| `@Get("/consent")` | `?oauth_state=` | `consentPage()` |
| `@Post("/consent")` | Form-encoded body | `consentSubmit()` |
| `@Post("/token")` | Form-encoded body | `token()` |

**`authorize()` logic**:
1. Validate `client_id`, `redirect_uri`, `response_type=code`, `code_challenge`, `code_challenge_method=S256`
2. Look up `OAuthClientEntity` — if not found or URI mismatch → 400 error page
3. If `requireSession() != null` → redirect to `/oauth2/consent?oauth_state=<new-uuid>` (store pending auth first)
4. If no session → store `OAuthPendingAuthorizationEntity`, redirect to Okta with our UUID as state

**`consentPage()` logic**:
1. Read `oauth_state` query param
2. Require session (redirect to login if none)
3. Look up `OAuthPendingAuthorizationEntity` — if expired/missing → 400
4. Look up `OAuthClientEntity` for display name
5. Return inline HTML response

**`consentSubmit()` logic**:
1. Parse form body: `oauth_state`, `action`
2. Require session
3. Look up and delete `OAuthPendingAuthorizationEntity`
4. If `action=allow` → create `OAuthAuthorizationCodeEntity`, redirect to `redirect_uri?code=X&state=Y`
5. If `action=deny` → redirect to `redirect_uri?error=access_denied&state=Y`

**`token()` logic**:
1. Parse form body: `grant_type`, `code`, `redirect_uri`, `client_id`, `code_verifier`
2. Look up `OAuthAuthorizationCodeEntity` — validate: exists, not expired, not used, client_id match, redirect_uri match, PKCE match
3. Mark code as used
4. Look up `UserSessionEntity` with `code.sessionToken()` to get remaining expiry
5. Return `{"access_token": sessionToken, "token_type": "Bearer", "expires_in": secondsRemaining}`

### Phase 4 — Modifications to Existing Components

#### `AbstractProtectedEndpoint` — add bearer token

```java
protected String getSessionToken() {
    // 1. Check Authorization: Bearer header
    String authHeader = requestContext().requestHeader("Authorization")
        .map(HttpHeader::value).orElse("");
    if (authHeader.startsWith("Bearer ")) {
        String token = authHeader.substring(7).trim();
        if (!token.isBlank()) return token;
    }
    // 2. Fall back to SESSION cookie (existing)
    String cookieHeader = requestContext().requestHeader("Cookie")
        .map(HttpHeader::value).orElse("");
    return parseCookie(cookieHeader, "SESSION");
}
```

No other changes to `AbstractProtectedEndpoint`. `requireSession()` calls `getSessionToken()` and already handles null/blank/expired correctly.

#### `AuthEndpoint` — callback OAuth flow detection

In `callback()`, after session creation (before the final redirect), add:
```java
// Check if this Okta flow was initiated by an OAuth 2.1 authorize request
var pendingOAuth = componentClient.forKeyValueEntity(state)
    .method(OAuthPendingAuthorizationEntity::get).invoke();
if (!pendingOAuth.isEmpty() && !pendingOAuth.isExpired()) {
    // OAuth flow — redirect to consent (pending auth keyed by same Okta state)
    return HttpResponse.create()
        .withStatus(StatusCodes.FOUND)
        .addHeader(Location.create("/oauth2/consent?oauth_state=" + state))
        .addHeader(RawHeader.create("Set-Cookie",
            "SESSION=" + sessionToken + "; HttpOnly; SameSite=Lax; Path=/"));
}
// Regular login flow — redirect to dashboard (existing behaviour)
return HttpResponse.create()
    .withStatus(StatusCodes.FOUND)
    .addHeader(Location.create("/?flash=login"))
    .addHeader(RawHeader.create("Set-Cookie",
        "SESSION=" + sessionToken + "; HttpOnly; SameSite=Lax; Path=/"));
```

Note: `OAuthPendingAuthorizationEntity` and `OidcPendingLoginEntity` use separate entity types and separate component IDs, but are both keyed by the same Okta `state` UUID. The `AuthEndpoint.callback()` looks up both independently.

### Phase 5 — MCP Endpoint 401 Response

The existing MCP endpoints (`SalesforceEndpoint`, `ZohoDeskEndpoint`, `GenericMcpEndpoint`) currently redirect unauthenticated requests to `/login`. For MCP clients, they should return `401 + WWW-Authenticate`. 

Add a helper method to `AbstractProtectedEndpoint`:
```java
protected HttpResponse unauthorizedForMcp() {
    String prmUrl = System.getenv().getOrDefault("MCP_BASE_URL", "http://localhost:9000")
        + "/.well-known/oauth-protected-resource";
    return HttpResponse.create()
        .withStatus(StatusCodes.UNAUTHORIZED)
        .addHeader(RawHeader.create("WWW-Authenticate",
            "Bearer realm=\"mcp\", resource_metadata=\"" + prmUrl + "\""));
}
```

The MCP-facing endpoints use `unauthorizedForMcp()` instead of `redirectToLogin()`.
